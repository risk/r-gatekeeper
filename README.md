# r-gatekeeper

A TypeScript utility library.

## Installation

```bash
npm install r-gatekeeper
```

## Usage

```typescript
import { /* your exports */ } from 'r-gatekeeper'
```

## Development

```bash
# Install dependencies
npm install

# Run tests
npm test

# Build the project
npm run build

# Run linting
npm run lint

# Format code
npm run format
```
